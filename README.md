# 기억 압류 관리국: 404호 소각로 (Incinerator No. 404)

디스토피아 데스크 시뮬레이션 겸 비주얼 노벨 웹 게임. 서버 없이 `index.html` 을 더블클릭하면 바로 실행된다(`file://`).

## 실행

| 방법 | 설명 |
| :- | :- |
| `index.html` 열기 | 개발용. 파일이 나뉘어 있어 수정이 쉽다 |
| `dist/incinerator-404.html` 열기 | 모든 CSS·JS를 한 파일에 담은 배포용. 휴대폰 파일 앱이나 메일 첨부로 그대로 열 수 있다 |
| `node tools/build.js` | 원본을 고친 뒤 `dist/` 단일 파일을 다시 만든다 |
| 주소 끝에 `#debug` | 챕터 바로가기·의심도 조절 디버그 패널 |

## 역할 분담

- **Claude Code**: 엔진, 상태 관리, UI/UX, 연출, Web Audio 절차적 사운드 (`js/`, `css/`, `index.html`, `tools/`)
- **Gemini**: 세계관, 대사, 압류 기억 텍스트, 분기 설계, 일러스트 (`data/story-data.js`, `assets/`)

`data/story-data.js` 는 제미나이 시나리오 v1(5일, 압류품 14개, 엔딩 3종)이다. 대사는 원문 그대로이고, `[Claude]` 주석이 붙은 3줄만 엔진 연결용으로 추가했다.
데이터 형식은 [`docs/DATA_SCHEMA.md`](docs/DATA_SCHEMA.md) 를 따르며, 제미나이 v1 형식은 엔진이 자동 변환한다(16장).
일러스트(`assets/bg/`, `assets/chars/`)가 아직 없어 기본 배경과 실루엣으로 표시된다.

## 폴더

```
index.html            화면 구조
css/style.css         스타일, 반응형(휴대폰 390px ~ 데스크톱), 글리치·훼손 연출
js/audio.js           Web Audio 사운드: 타자기, 도장, 판독기, 소각 노이즈, 서랍, 글리치, 마커, 무드 앰비언트, 기억 상실 로우패스
js/engine.js          데이터 정규화·점검, 상태, 조건식, 대화, 판독/등급/소각/은닉, 수첩·매뉴얼·달력·서랍, 보고서, 최후의 타이핑, 엔딩, 저장
data/story-data.js    window.GAME_DATA (제미나이 담당)
assets/chars|bg|mem/  초상화·배경·압류품 삽화 (제미나이 담당)
tools/build.js        단일 HTML 빌드
docs/DATA_SCHEMA.md   데이터 규격
```

## 구현된 게임 루프

1. **날짜 카드 → 출근 대화** (민원 창구 비주얼 노벨 뷰, 타자기 출력, 선택지, 조건 분기)
2. **판독**: 트레이의 기억 결정을 판독기로 끌어오거나 누르면 회상 텍스트·손글씨 메모·열량이 출력된다.
3. **등급 도장**: 매뉴얼의 등급표를 보고 S~C 도장을 찍는다. 오판정은 감찰 의심도 상승.
4. **소각**: 열량이 등대 출력에 더해지고 화면이 밝아진다. 주인공 관련 기억이면 글리치, 소리가 먹먹해지는 로우패스, 수첩 문장이 실시간으로 `█` 처리되고, 매뉴얼·달력·사번 표기가 깨지기 시작한다.
5. **은닉**: 서랍에 보관(다시 열람 가능). 등대가 어두워지고 감찰 의심도가 오른다. 조건에 따라 수첩에 단서가 생긴다.
6. **업무 보고서**: 할당량 달성 여부, 처리 결과 문장. 미달이면 의심도 상승. 의심도가 한도에 닿으면 적발 엔딩.
7. **최후의 타이핑**: 마지막 날 입력창에 압류 대상 이름(예: `이리나`, `0404`)을 직접 입력해 소각로에 투입 → 엔딩 분기.

진행은 매일 시작 시점에 브라우저(localStorage)에 자동 저장되고, 타이틀에서 이어할 수 있다.
